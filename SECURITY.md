# Security

## Reporting

Do not disclose vulnerabilities, private media or tokens in public issues. Once hosted, use **Security → Advisories → Report a vulnerability** if the owner has enabled private reporting. Otherwise contact the repository owner privately through an established channel. No support address or response-time commitment is invented here.

Include app version, affected component, synthetic reproduction and impact. Redact tokens, device identifiers and private data. Real backend testing requires the owner's authorization.

## Scope

Version 1.0.3 is the baseline; no formal support window is promised. Devnet is a test environment. Hashes and signatures do not prove an event's truth. Keystore protection varies by device.

Local evidence, `.env` files, keys and machine paths are excluded. API hostnames are public configuration. If a real secret is committed, rotate it and assess exposure before publishing history; deleting the file alone is insufficient.
