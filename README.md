# MDFP · MD Вільні люди

Android-застосунок для фіксації фото, відео й аудіо, перевірки цілісності файлів та передавання записів до сервісів MD System.

**Розроблено ГО “Центр цифрової довіри” · NGO Center for Digital Trust.**

## Можливості

- Фото, відео та аудіо з камери й мікрофона; координати за наявності дозволу.
- SHA-256 для медіафайлу та канонічного запису; підпис через Android Keystore.
- Локальне збереження записів і черга синхронізації з сервером.
- Окрема передача метаданих до API та медіафайлів до Vault.
- Завантаження через Wi-Fi або мобільну мережу, режим лише нетарифікованої мережі та ручне завантаження.
- Статуси обробки, локальна перевірка цілісності, QR-код відбитка та обмін файлом.
- Збереження обраної мови й адаптивна іконка Android.

## Початок роботи

Встановіть Flutter 3.24.5, Java 17 та Android SDK (platform 35, build-tools 34.0.0). У корені репозиторію:

```sh
flutter pub get && flutter analyze --no-pub && flutter test --no-pub
```

Для підключеного Android-пристрою: `flutter run`. Для тестового APK: `flutter build apk --release --no-pub`. Докладні команди, конфігурація серверів і підпис — у [посібнику зі збірки](docs/BUILD.ru.md).

## Межі застосування

Перша реєстрація пристрою потребує доступного API. Після реєстрації записи можуть очікувати синхронізації локально. Android може відкладати фонові завдання; 15 хвилин — інтервал планування, а не гарантований час доставки.

Хешування перевіряє цілісність байтів, але саме по собі не доводить правдивість події, координат чи часу. Апаратний захист ключа залежить від пристрою. Поточна серверна інтеграція використовує Solana Devnet — тестову мережу. Код серверів Azure, Vault та агрегатора не входить до цього репозиторію.

Базова версія 1.0.3 пройшла 27 автоматичних тестів та статичний аналіз. Фізичний тест 4G із SIM-карткою до цих перевірок не входив. GitHub Actions запуститься після завантаження репозиторію; успішний статус CI наперед не заявляється.
