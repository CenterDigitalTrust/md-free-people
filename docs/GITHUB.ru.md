# Размещение на GitHub

Имя: **mdfp-mobile**. Папка подготовлена как самостоятельный Git-репозиторий с веткой `main`; удалённый адрес не задан. Учётная запись и видимость GitHub не выбирались.

1. Создайте пустой репозиторий `mdfp-mobile` в нужной учётной записи. Не добавляйте автоматически README, `.gitignore` или лицензию.
2. Откройте папку в GitHub Desktop через **Add existing repository** либо подключите фактический удалённый адрес через Git.
3. Если начального коммита ещё нет, просмотрите staged-файлы и создайте его под своей Git-учётной записью.
4. Опубликуйте `main`. Проверьте **Android checks** во вкладке Actions.
5. About: `Android evidence capture and integrity verification by NGO Center for Digital Trust.` Темы: `flutter`, `dart`, `android`, `digital-trust`, `evidence`, `localization`.
6. Включите private vulnerability reporting; настройте защиту ветки после первого успешного CI.

CI выполняет анализ, тесты и сборку debug APK. Его артефакт подписан временным ключом runner и не предназначен для обновления прежнего APK. Проверенный тестовый APK 1.0.3 хранится отдельно от истории исходников; его можно прикрепить к Release с указанием тестовой подписи.

Владелец выбрал [лицензию MIT](../LICENSE); файл уже включён в репозиторий. Сохраните уведомления сторонних компонентов. Не публикуйте реальные доказательства, ключи и серверные токены.
